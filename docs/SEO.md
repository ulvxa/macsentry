# Repo discoverability

## GitHub description (About)

> Free, open-source disk cleaner and storage analyzer for macOS. Finds Xcode DerivedData, node_modules, Homebrew/npm caches, app caches, leftovers from uninstalled apps, duplicates and old large files. Nothing is deleted directly: picks go to quarantine, then the Trash. Native SwiftUI, a CleanMyMac/DaisyDisk alternative.

## Homepage

Use `https://github.com/ulvxa/macsentry/releases/latest` until there is a project site. A GitHub Pages site at `https://ulvxa.github.io/macsentry` is the natural upgrade later.
